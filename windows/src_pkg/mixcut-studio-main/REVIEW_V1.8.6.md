# V1.8.6 验证记录

## 行为

素材首页在新扫描存在异常视频时显示清理按钮。一次确认后，后端仅从当前库的扫描错误记录选取视频，不接受客户端指定任意文件路径。扫描记录保留文件大小、修改时间和文件系统身份，清理时重新检查并用 FFprobe 读取视频信息，不做全长解码。仍异常且没有变化、任务引用的视频移入系统废纸篓。音乐、目录访问错误、缓存写入错误、老版无身份扫描记录均不清理。

扫描与清理共用互斥锁；清理失败逐文件保留，可再次尝试。已恢复正常或已变化的视频保留并提示重新扫描。扫描统计显示的是该轮历史统计；红色异常明细在清理后同步更新。

## 验证

- 318 项 unittest 通过。
- 新增 9 项回归测试：扫描身份快照、清理及持久化、文件变化、恢复正常、任务引用、音乐及目录保留、废纸篓失败、扫描互斥、复查期间变化。
- macOS 安装包构建通过；内嵌版本 1.8.6、FFmpeg/FFprobe 检查通过。
- 安装包实际服务 + Chromium 页面按钮验证通过：真实无效 MP4 移入系统废纸篓、正在变化的文件保留、正常视频和音乐保留、接口返回 200、异常列表及数据库更新。
- 以上测试使用隔离临时目录，没有清理用户的真实素材或更换正在运行的应用。

## 限制

扫描与清理时的文件身份复核能识别两次检查之间的变化，不能判断一个长时间没有继续写入的录制程序以后是否还会继续写入。请在录制结束后清理。外接磁盘无法使用废纸篓时保留文件并显示失败，不直接永久删除。
