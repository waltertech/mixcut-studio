# V1.8.11 验证说明

## 版本基线

在现有 V1.8.10 上新增普通混剪音乐轮数，保留 V1.8.9 的日期目录命名与 V1.8.10 的直接 HTTP 启动检查。独立音乐 Set 页面及制作规则不变。

## 实现

- 新表单默认两轮；接口或旧方案缺少轮数字段时仍按一轮，避免升级使旧任务自动变长。
- 分别保存 music_base（一轮顺序）、music_repeats（1～4）、music_base_duration。实际 music 清单完整展开全部轮次，既有渲染和曲目文档按真实清单处理。
- 方案预览和任务列表提供逐条选择。只能修改未开始制作、无输出、无既有制作结果的 pending 任务。执行器在读取任务前用同一存储锁登记内存占用，防止“仍显示待处理但已被执行线程领取”时修改计划。
- 调序、随机换位、重新排列、更换文件夹操作围绕一轮歌单进行，随后重新展开相同轮次。单条轮数改动不会重新随机歌曲，也不会修改其他任务的音乐或视频内容；批内使用计数会重新统计。
- 初次规划按全部音乐总时长生成视频。修改轮数时单源按原视频完整长度循环，最后一段截断；多源重复已有画面片段以覆盖音乐。
- 音乐播放轮数为4，仍只按一条成功任务记录文件夹使用历史。音乐源不删除。原有静音检测缓存和可选交叉过渡继续适用。
- 仅保存一轮编辑列表，减少界面重复行；实际文档完整列出全部轮次。时长、歌曲次数、预计输出空间同步计算。

## 性能与限制

轮数选择和方案重算只处理已缓存的媒体元数据，不做额外解码或指纹检测。作品时长增加，实际音频拼接、视频编码、输出大小和缩略图数量也会增加。此轮没有新增长时间压力测试。正在制作或已经完成的作品若需要改轮数，应重新规划制作，不直接改现有成品。
