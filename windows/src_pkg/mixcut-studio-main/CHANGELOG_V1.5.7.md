# V1.5.7

- 成片按“成品保存根目录／日期／编号-根目录名称／视频及同名文档”保存，一条任务一个目录。目录在生成方案时预约，同日不同方案连续编号，原地渲染完成。
- 审核通过保留成片原处，不复制、不迁移、不为归档计算整段文件哈希。继续清理缓存和可安全删除的原视频素材，原音乐保留。
- 审核不通过将整个成品目录移至系统废纸篓，同时沿用问题原视频素材清理规则。
- 删除单条、选中任务或全部任务时，将成品目录移至系统废纸篓再移除任务记录。执行中先请求终止，超时或移动失败保留记录供重试。
- 旧版共用输出目录仅回收对应视频和同名文档，不整体移动共享目录；旧已审核任务继续使用旧归档位置。
- 隐藏旧审核目录设置，新增每条任务“打开成品文件夹”。取消只删记录的提示，删除全部任务明确标注。
- 缩略图和渲染临时文件保留在缓存区；方案清单放入本地状态目录，不与成片混放。
- 贴图版本使用相同目录规则；审核替代版后未通过审核的旧成片移至废纸篓，单独审核通过的原成片保留。
- 版本1.5.7，接口协议13，防止新版界面连接旧版后台执行不一致的审核操作。
