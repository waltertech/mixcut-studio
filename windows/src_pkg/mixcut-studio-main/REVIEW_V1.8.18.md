# V1.8.18 验证记录

## 当前规则

普通新任务标记 output_naming=bundle-library-v1。先预留独立作品目录，再生成“目录编号_末级曲库目录名.mp4”。TXT同名。曲库名称来自原目录，不根据最终视频长度重算，1～4轮保持同名；手动换曲库重算名称。目录中没有规范时长/首数/ID也保留可用目录标签，不编造来源。多目录去重列出各名称，过长时截短并附摘要；标准来源ID尽量保留。文字NFC归一、空白和特殊符号归一下划线，文件名限制220 UTF-8字节。

新贴图版本用新作品目录编号及来源目录标签。独立音乐Set模块未更改业务。旧duration-youtube-v1及更早命名策略继续兼容，既有作品不批量改名。

跨天审核的bundle_relocation意图包含旧/新文件名；先移动目录，再同盘改视频及已有TXT名称，最后提交最终路径。中断可继续，已有冲突内容不覆盖。成片文件及TXT的inode在同盘改名中保留。
