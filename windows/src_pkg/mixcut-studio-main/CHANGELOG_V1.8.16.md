# V1.8.16

- 普通混剪新任务的视频名改为“实际成片时长-末级音乐文件夹中的 YouTube ID.mp4”，如 `1小时50分30秒-M9q9pvKB7hY.mp4`。
- 规划阶段显示预计时长；成片验证完成后按实际时长确认名称，TXT 原曲路径及曲目表沿用同一主文件名。
- 识别曲库“时长_首数_ID”、附加标签、方括号 ID 等命名，保留 ID 中的大小写、连字符、下划线。只从歌曲所在末级目录识别，不使用分类目录。
- 混用多个来源目录时按播放顺序去重列出多个 ID；未找到时明确使用“未识别ID”，不从分类名或歌曲内容推测。
- 成片在自身任务目录内重命名，不复制大视频；重名加序号保护现有文件，保存重命名意图用于中断恢复。
- 已有任务和完成作品不批量改名；文件夹日期编号、保留/回收和音乐保护规则不变。独立音乐Set交接模式不变。
