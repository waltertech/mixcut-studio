# V1.5.0 代码 review 与功能自测

## 实现与检查

静音分析放在独立的mixcut/nonstop.py，通过现有Store持久化，渲染器负责裁剪与淡化，任务服务负责状态和实际时长保存。没有增加内容指纹或大体积音频预处理副本。扫描和生成方案路径不触发静音检测。

检查了串行检测锁、并发复用、文件变化失效、取消检测、子进程关闭、超时、全静音的有限扩大范围。失败结果不入库。源音乐只读，审核和任务删除不删除曲库音乐。

计算时扣除首尾静音及跨曲重叠并保留0.05秒舍入余量。规划时长单独保存，调整后按制作时长校验；不足时不补歌、不按原最低时长判失败。元数据高估导致的实际音频不足使用流复制截短已生成视频，再完整校验。成品损坏、缺少声音或文件不可读不能标为成功。

界面进度通过原有局部更新显示，不随每首检测重新创建整个任务列表。新增时长差值在任务行下显示。缩略图、审核、删除和音乐缓存持久化相互兼容。

## 实际限制

合成测试证明处理逻辑，不代表你的全部真实曲库已经试听。-50dB、0.3秒和0.5秒是初始参数；只处理首尾，不做BPM对拍。首尾超60秒仍全静音时将歌曲视为不适用并沿用最多三轮换歌重试。首次检测受机械盘定位、格式和并行渲染负载影响，没有承诺固定耗时。已有旧方案保留原配置，使用本功能应重新生成开启无缝衔接的新方案。

此次仅在临时隔离数据中自测，没有修改用户素材库、现有任务数据库或替换已安装应用。
