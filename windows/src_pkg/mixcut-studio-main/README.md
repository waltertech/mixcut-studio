# 本地批量混剪工具

用本机视频和音乐批量生成不同成片。无需账号、Agent、API Key 或云端上传。

## 启动

从源码运行时，在 Mac 双击 `启动混剪工具.command`，页面会在默认浏览器打开。安装 macOS 应用后，双击应用会打开独立的本机窗口。

从源码运行需要 Python 3.10+、FFmpeg 和 ffprobe；macOS 安装包已内置运行所需组件。

安装新版时，如果旧后台没有执行中的任务，启动器会先关闭旧进程并启动新后台；若仍有任务在执行，会提示等待其结束后再打开新版。窗口右上角显示的版本来自运行中的后台，不会随磁盘上的安装文件替换而改变。

也可以在本项目目录运行：

```bash
python3 launch.py
```

启动器把后台日志保存到 `.mixcut/server.log`。关闭应用窗口不停止导出；退出后台请先暂停并等待当前条完成，再点击退出后台。电脑休眠、关机或结束后台会中断运行，重开工具后可继续未完成条目。

## 单文件夹音乐（V1.5.4）

在“剪辑设置”选择“单文件夹音乐”。素材页音乐路径作为根目录，直接子文件夹分别作为一组，后代目录归入同组；根目录散放音乐不参与。每条任务只用一组音乐，整组任务优先分配不同文件夹，用完后才重复。组内全部有效音乐随机排列，不足则重新洗牌循环；此模式不受歌曲首数和逐首勾选限制。方案里可以手动选文件夹、随机换文件夹、重新排列音乐，查看文件夹任务次数及歌曲清单次数。音乐明细默认收起。

## 操作流程

1. 在素材页点击视频、音乐路径旁的“选择文件夹”，通过系统窗口选择目录，再扫描。音乐会递归读取任意层级，因此可直接选择包含音乐、封面和文案的母文件夹；先按扩展名筛选候选文件，再用 FFprobe 核对媒体流和时长。视频支持 MP4、TS 等常用格式，音乐支持 MP3、M4A、FLAC 等常用格式。更换一个路径时，只刷新对应素材库；扫描期间显示候选处理进度，完成后更新素材列表。
2. 选择导出文件夹；工具记住该目录。每次成功生成方案会预留一个日期编号子文件夹，例如 `2026-09-22_001`，当天后续批次依次递增，已有目录不会被覆盖。
3. 选择参与的素材，需要时填写视频分组。每首已选歌曲都可以排在第一首。
4. 在“剪辑设置”页设置剪辑模式、期望时长范围、输出数量与音乐组合规则。导出分辨率、帧率、视频码率和音量放在页面上方；素材只在“素材”页选择，这里显示已选数量，不重复列出全部文件。
5. 生成方案，检查实际时长、视频区间、歌曲顺序和实际保存位置。顶部只显示简短的方案统计；素材的名称和本批使用次数在每条方案内查看。候选池模式按整批轮转素材，草稿阶段可逐项随机替换，或刷新一整条任务的音乐；也可拖动歌曲或用上下箭头调整顺序。勾选方案后可批量删除任务记录，删除成功会立即显示剩余数量；原定目标数量保留作参考，成片文件不会随记录删除。
6. 开始批量导出，在任务页逐条查看进度、暂停、继续或重试。完成视频的预览图固定每 30 秒生成一张；点“查看与审核”展开该任务的视频、图片和审核操作。

新批次保存在 `你选择的导出文件夹/日期_编号/`，视频名称使用音乐风格和编号，例如 `Hindi DJ Remix_001.mp4`。每个成功视频旁会生成同名 `.txt`，按歌曲实际播放顺序逐行写入歌曲所在文件夹的绝对路径；点击“通过审核”时，MP4 和同名 TXT 会一起进入审核目录。`manifest.json` 记录完整源片段和音乐顺序。旧批次仍保留原有文件名和保存位置。取消文件夹选择不会修改路径；更换视频或音乐目录后需要重新扫描。

素材刷新会复用未变化文件的媒体信息和内容指纹；同一磁盘内移动或重命名、且仍保留支持格式扩展名的文件也可复用。扩展名不在支持范围内的文件会快速跳过；扩展名符合但内容不符的文件不会收录。扫描结果区分目录文件、候选文件、识别成功、重复和失败的数量。新增媒体仍需读取内容并计算指纹，因此首次扫描大型新媒体库仍可能花较长时间。音乐扫描先显示容器估算时长，生成方案前才对所选歌曲完整解码并精确校验时长。扫描时不能生成方案，避免使用尚未完成的素材清单。音乐播放器只在点击“试听”时创建，减少大曲库造成的界面卡顿。

## 按音乐风格命名

风格来自文件夹名称，不进行音频猜测。当前已识别 `Hindi DJ Remix`、`Hindi POP Songs`、`Old Hindi Songs`；也支持其他风格目录名。

可以直接选择一个风格目录，或选择包含各风格子目录的音乐总目录。已知风格目录下面可以再放专辑子目录。其他风格按音乐总目录下的第一层子目录命名；直接平铺的歌曲使用所选文件夹名。

- 同一风格多首歌曲：`Hindi POP Songs_001.mp4`。
- 跨风格歌曲：`Hindi DJ Remix + Old Hindi Songs_002.mp4`，按实际涉及的风格组合命名。
- 日期编号子文件夹规则不变；通过审核时保留文件名，贴图新版本也继承音乐风格。
- 若仍使用原来的 `去重歌曲03` 文件夹名，新视频会以该文件夹名命名。按风格整理后重新扫描即可。

## 两种模式

“源视频时长必须大于（分钟）”筛选原始视频文件：默认0不限制，填5只允许超过300秒的源文件，正好5分钟也会排除，支持小数。它不改变成片或片段时长规则，单源/多源模式与定时任务都遵守；没有符合条件的素材时，手动生成会提示，定时任务继续等待更长的新视频。

**单源连续截取**：每条只截取一个视频的连续区间。可允许不同成片间重叠，也可不重叠顺切。目标成片时长超过源视频可用长度时，该方案不可行。

**多源拼接**：每条至少从两个不同视频取连续片段，按设置的段长范围拼接。同条内不重复使用同一源视频的重叠区间。可以限定在同一人工分组内选素材。

## 音乐与时长

候选池模式在整批任务中优先分配使用次数少的歌曲，曲库不足时才进入下一轮；每条任务内不重复选同一首，选中歌曲的总时长须覆盖目标成片时长。选定歌曲集合后随机排列播放顺序，不再用歌曲时长决定首位；可设置每条最多 20 首。固定歌曲集合模式仍按原定义重复使用整组歌曲。为便于复现，可手动填写随机种子；留空时每批生成新种子。

成片在目标时长处结束，因此末首歌曲可能只播放一部分。音乐不变速、不自动循环，编码允许极小的帧/采样量化差异。若要完整播放所有歌曲，请让目标时长与所选音乐总长相符。

固定 5 首不同歌曲可有 120 种顺序。歌曲数量、时长范围及源视频长度会共同限制可生成数量。草稿中可单独替换视频；若新片段改变目标时长，程序会联动重选这一条任务的完整音乐列表，重选失败时保留原方案。也可选择“联动换视频和音乐”主动尝试新时长。

## 差异与默认值

每个已完成视频下方提供关键帧画廊：每 30 秒一张，直接展示全部。鼠标悬停或键盘聚焦可查看大图，点击缩略图可定位播放器，Escape关闭大图。缩略图按需加载并缓存，不修改成片。

## 审核通过与归档

在素材页或任务结果页设置“审核通过文件夹”，支持系统选择窗口和手动输入，设置会自动保存。查看成片后，点击该视频的“通过审核”，工具会把完整MP4复制到审核目录下的日期编号子文件夹。同一批次在同一个审核目录里的通过视频放在同一子文件夹中。

复制并校验成功后，审核目录按 `日期/音乐类型_编号/` 组织，每条视频一个独立文件夹，内部 MP4 与 TXT 同名，例如 `2026-09-25/去重歌曲03_001/去重歌曲03_001.mp4`。确认审核副本完整后会删除制作目录中的对应 MP4、TXT 和临时片段。已审核任务使用的原始视频文件也会在所有引用它的任务都审核通过或被已审核贴图版替代、归档副本校验成功且原文件与扫描记录一致后删除；若仍有未处理的引用，后台会继续检查。审核完成的任务会从列表消失；尚需进行原片清理的关联信息暂存在后台，清理完成后自动移除。重复审核不会复制多份。空间不足或复制失败不会被误标为通过，可修正目录后重试。

任务结果页提供全局“一键审核”，按任务创建与序号顺序逐条审核已完成视频；未完成、已审核和已被贴图版替代的条目会跳过。遇到归档错误时立即停止，页面显示失败原因；修复后再次点击可继续审核剩余条目。审核在后台运行，关闭窗口不会中断。

旧任务若没有保存原视频根目录，重新扫描原目录后可重试清理原片与制作成片。程序只会在当前扫描索引能确认同一源文件、文件内容未变且所有关联任务的归档副本完整时删除原片。任务页点“删除该条”会立即从列表移除记录，无需确认；也可勾选多条删除或点击“清空任务记录”。这些操作不会删除导出或审核文件，也不会因原片尚未清理而被阻止。删除执行中的任务会请求停止该条，并立即隐藏记录；渲染进程退出后清除后台条目。主动删除尚未审核的记录会放弃该任务之后的审核及依赖这条记录的自动文件清理，文件需自行管理。

## 贴图库与位置模板

1. 打开“贴图库”，导入PNG、JPG、WEBP或GIF图片，单文件最多12MB。动态GIF会在成片中循环播放；透明背景静态贴图建议使用PNG。
2. 点击贴图加入画布；可以选择一条现有成片作为参考画面，拖动贴图定位，或输入位置、宽度、不透明度和出现/结束时间。结束时间留空表示持续到视频结尾。
3. 为模板命名并保存；同一个模板最多8层贴图。位置和尺寸按画面比例记录，适配当前16:9的720p/1080p输出。
4. 生成前，在“剪辑设置”的“贴图模板”中选择已保存模板。默认“不添加贴图”；保存模板本身不会自动启用。
5. 审核已有成片时，可在视频旁选择模板，再点击“生成贴图版本”。它会排队生成一个独立日期目录的新批次，音轨直接复制。查看新版本并点击“通过审核”后，程序校验审核副本，再清理未单独审核的原成片及可安全删除的原素材。如果原视频已经单独审核，其审核归档会保留；其他贴图任务仍依赖原成片时，会等待其完成。升级前创建且已审核的贴图任务不会仅因启动新版而追溯删除原视频，可在任务中手动重试清理。

审核时套用模板是追加覆盖层，不能移除已经烧录到原视频中的贴图。模板编辑不会改变之前已经生成的方案：每个批次都保存自己的模板快照。当前不支持SVG。

## 定时任务与持续补足

先在“剪辑设置”配置剪辑方式、时长、音乐规则、导出规格和可选贴图，再进入“定时任务”：

1. 填写任务名称、开始时间、一次/每天/每周重复方式。
2. 设置每轮目标数量（例如50）和检查间隔（例如10分钟）。
3. 选择视频、音乐、导出目录；可以复制当前目录和剪辑设置，保存成独立快照。
4. 勾选“启用任务”后保存。未勾选则只保存配置；“立即启动”可手动开启一轮，不必等待设定时间。

到点会扫描配置的文件夹：如果目标50条但当前只能规划20条，就先生成20条，再按间隔检查新增或变更素材，逐步补足到50条。累计数只计算成功成片。当前一轮的音乐顺序、画面方案及单源不重叠区间会跨检查记忆，不会把相同方案反复计数。

下一轮定时任务启动时（包括另一条任务或每日/每周的下一次），上一轮剩余目标取消，未完成编码中断、未开始的队列取消，已经完成的文件保留。旧目标不能恢复或把欠数带入新目标；新一轮重新按其文件夹与配置计算目标。手动创建的批次不受替换影响。每轮内部去重，不承诺跨不同定时轮次从不复用原素材。

页面显示累计进度、下次检查时间、等待原因和历史接管记录。“立即检查素材”可以主动重试当前一轮的未用方案；“停用并取消本轮”会关闭未来触发并取消正在等待的目标。定时生成不会自动通过审核。

**本机后台必须运行，电脑需要处于唤醒状态。** 关闭网页不影响运行，关机或休眠期间不会执行。重启后只补启动最近一个错过的定时轮次，较早轮次不会积压执行；当前有效目标与未完成批次可以恢复。

歌曲时长和去重约束仍有效：如果瓶颈是可用音乐排列不足，仅增加视频也未必能达到目标，需要增加音乐或调整规则。定时任务使用文件夹内全部可用素材，以便识别后来新增的文件；第一版不支持手工视频分组限定，可为不同组选择独立文件夹分别建任务。

- 候选池模式在整批内优先分配未使用的音乐；视频片段优先使用尚未被占用的源文件时间区间。素材总量或长度不够时，按配置允许情况复用。固定歌曲集合模式会复用整组歌曲。
- 方案统计会直接显示“不同歌曲顺序”；固定歌曲集合会使用相同歌曲但改变排列，候选池模式会同时改变歌曲子集和顺序。
- 显示的画面重合度按相同源文件时间区间计算，不是视觉语义检测或平台去重保证。
- 默认输出 720p、30fps，等比适配，原音静音、音乐音量 100%。
- 保留原音时可调低音量，工具不自动区分游戏音效、主播讲话和原有背景音乐。
- 默认串行导出，最多自动尝试 3 次；持续故障需在修复后手动重试。
- 暂停/停止在当前成片处理完成后生效；恢复时保留成功项，未完成条目重新处理。

## 常见情况

| 提示或现象 | 处理 |
|---|---|
| 未找到足够方案 | 扩大音乐池、放宽时长或减少数量 |
| 单视频不够长 | 缩短目标成片时长，或使用多源模式 |
| 多源段长无法满足 | 缩小最短段长、扩大最长段长，或加入更多源视频 |
| 素材已改变/不存在 | 恢复原文件，或重新扫描并生成新批次 |
| 输出位置已有无效文件 | 先检查并移走该文件，再重试；工具不直接覆盖 |
| 已完成文件找不到 | 检查是否移动了输出文件，再选择恢复文件或重试 |
| 磁盘不足 | 清理空间或改用其他输出位置创建新批次 |
| 浏览器打不开 | 查看 `.mixcut/server.log`，确认端口 8877 未被其他程序占用 |

## 加快渲染

- 导出规格选择“自动硬件加速”：Mac 优先使用 VideoToolbox；Windows 依次尝试 NVIDIA NVENC、Intel QSV、AMD AMF，不可用时自动回退软件编码。
- 速度优先时使用 1280×720、30fps。1080p 的像素数约为 720p 的 2.25 倍，60fps 又约为 30fps 的两倍。
- 没有可用显卡编码时可选择“软件极速”，会使用 x264 ultrafast，速度更快但文件通常更大；“软件高质量”更慢。
- 工具仍保持单条顺序渲染，避免多条并发争抢解码器、磁盘和显存导致整体更慢或不稳定。

原始游戏画面内已有的文字、主播头像和性能数据会保留。第一版不自动识别精彩片段或评估歌曲吸引力。

在剪辑设置开启“附带曲目曲名”，或在方案、任务中单独开关；勾选任务可批量开启或取消。成片同名 TXT 保留原曲文件夹路径，并追加按实际播放顺序编号的文件名曲目表。循环重复逐次列出，未播放歌曲不列出。已完成任务更新文档无需重新渲染。

## 审核归档编号（V1.5.6）

选择审核目录 `1006 aidj` 后，每条审核通过任务归档到其直接子目录 `001-1006 aidj`、`002-1006 aidj`。编号与歌曲及成片文件名无关，按已有新格式目录继续递增。旧归档不迁移。
