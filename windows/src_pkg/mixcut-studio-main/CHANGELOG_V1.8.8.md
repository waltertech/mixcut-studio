# V1.8.8

- 单文件夹音乐模式跨批次维护永久使用统计，保存到本地数据库，任务列表删除与审核自动清理不会移除此统计。
- 先保持同批文件夹尽量不重复，再优先选择“成功次数＋待制作数量”少的文件夹；相同次数优先选择更久没成功使用的文件夹，再随机挑选。
- 新文件夹从零参与。失败、取消、删除释放待制作占用，重试成功按同一条任务只记录一次。
- 手动生成、定时生成、随机更换文件夹共用分配依据；同时生成的方案依次登记占用。
- 方案音乐文件夹处显示规划时的历史成功次数、已有待制作数及本批使用数。
- 启动时自动从仍保留的成功任务补入历史；已删除且没有任务记录的过往作品不做磁盘遍历猜测。
- 不改变普通随机歌曲及独立音乐 Set 业务；无需读取音频内容或新增解码。
