# V1.5.4

- 新增“单文件夹音乐”模式；保留全路径音乐随机及旧固定歌曲集合模式。
- 音乐库根路径的直接子文件夹作为分组，后代目录归入同组；根目录散放歌曲、无有效音乐的文件夹不参与。
- 整组任务按最低使用次数随机分配文件夹，全部文件夹用过一轮后才复用；不会按歌曲长度或数量加权。
- 文件夹内全部歌曲按轮次洗牌；不足时追加下一轮，避免两轮交界连续播放同一首（只有一首时允许循环）。
- 单文件夹模式忽略最少/最多歌曲数及逐首勾选，使用组内全部有效音频。
- 方案可手动选择文件夹、随机换文件夹、重新排列、调整歌曲顺序及单曲替换；显示本组文件夹任务次数、歌曲播放次数与轮数。
- 刷新、视频时长变化和渲染坏音乐补救均保持所选文件夹；无可用歌曲时明确提示，不静默跨文件夹。
- 规划只读现有路径和时长元数据。歌曲列表按需展开；渲染只处理实际播放的前缀，循环歌曲复用静音检测结果；静音裁剪后不足时在同文件夹继续追加。
- 定时规划同步支持新模式；旧方案保留原有音乐分配规则。
- 前端、后台、原生窗口及 Windows 公共源码同步到1.5.4，接口协议升到11。
