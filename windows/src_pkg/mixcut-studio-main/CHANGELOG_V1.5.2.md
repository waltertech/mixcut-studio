# V1.5.2

- 正式混剪改为约180秒、按帧边界对齐的视频检查点；分段缓存位于本机应用数据目录 work/<方案>/<任务>/checkpoints。
- 正常渲染失败时，仅对出错片段尝试容错解码，再尝试同素材其他区间或其他低使用次数的视频；最多两次替代，补救限时180秒。
- 源素材已知异常区间保存到本地数据库，按路径、大小、修改时间区分版本；扫描和规划不增加全量解码。
- 分段中断可恢复，已完成片段复用；更改渲染规格会重新生成。
- 无可用替代素材时，已有可用片段可合成短成片并提示；无可用成片或补救超时时暂停该任务，释放执行位置继续后续任务。
- 保留V1.5.1的真实进展停滞180秒保护与分辨率切换修复。
- 音乐最终统一拼接，保留nonstop静音检测与交叉淡化；音乐源文件永不因本次补救、审核或删除任务而删除。
- 成片完成后清除分段文件；审核或删除任务清理任务工作缓存，活动任务退出后再清理。
- 界面显示分段渲染、素材补救、合成成片、素材异常待继续，并显示短成片与自动补救说明。

## 边界

- 首次正常渲染同样分段，增加本机SSD临时读写；没有贴图时最终视频直接拼接，不再次编码。启用原声混音时以PCM存储分段原声，避免音频编码延迟累计。
- 更换视频可能改变画面内容，跳过坏帧可能在出错位置有短暂画面跳变；成片仍需审核。
- 外接盘断开、音乐源缺失、空间不足等无法保证任务完成；保护后续任务并保留可恢复文件。
- V1.5.0/V1.5.1正在执行的旧任务没有分段检查点，无法追回旧进程已渲染的部分。
- 主动清除缓存会删除空闲任务检查点，之后需要重新渲染。
