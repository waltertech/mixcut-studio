## Review

- 缓存只管理应用数据目录中的生成文件；一键清理不触碰素材、成品、审核归档、贴图素材、任务数据库。
- 正在渲染的转换缓存和工作目录通过使用登记保护；审核产生的延后清理请求持久保存，读者结束后或后台维护时执行。
- 预览图片生成和读取期间暂缓清理预览缓存，避免删掉正在写入或发送的文件。
- 审核贴图版本时同步收集原任务的素材缓存，并清理原视频对应关键帧。
- 重试不改动成功任务；重试正在执行队列中先前失败的条目时，队列结束后会再次处理尚未执行的条目。
- 缓存占用读取文件元信息与磁盘分配量，不读取媒体内容，也不在每次进度轮询时全量扫描缓存。
- API 协议升级确保旧后台不会被新界面误认兼容。

## 使用说明

审核后共享缓存可被清理，其他尚未开始的任务需要时会从原素材重新生成。正在使用的缓存等待结束再清理。一键清理不会取消任务，但随后可能需要重新生成缩略图和转换缓存。清理未成功的文件保留并显示错误，可再次操作。
