EDITING RULES

剪辑设置

先选择素材和规则，再生成一批可复现的方案。

导出规格

视频码率设为 0 时沿用自动编码设置；设置固定码率可控制输出大小。720p/30fps 通常最快。并行数量为同时执行的任务上限，旧方案默认 1；暂停后等待所有执行中的任务完成。

画面组织

0 表示不限制；例如填 5，只使用超过 5 分钟的原始视频，正好 5 分钟也会排除。此项筛选源文件，不是设置成片或截取片段的长度；手动生成和定时任务均生效。

歌曲分配规则

整组优先使用不同子文件夹，用完后再随机轮转。包括子文件夹内的全部有效音频及更深层目录；根目录直接放置的歌曲不参与。此模式不限制歌曲首数。

整批优先分配未用歌曲；需要覆盖成片时长才进入下一轮。选定歌曲后再随机播放顺序，任意歌曲都可排第一。

在成片同名的原曲路径文档中，按实际播放顺序增加编号曲目表。可在方案或任务中单独调整。

参与素材

扫描后默认使用全部视频和音乐。需要排除文件或设置分组时，在“素材”页展开对应列表。

任务与结果

一条视频就是一条任务。审核通过保留原处；删除或审核不通过会将成品文件夹移至废纸篓。音乐保留。

通过审核后先校验归档副本，再删除制作目录成片；原始录屏在所有引用任务审核或移除后删除。失败时可重试清理。
