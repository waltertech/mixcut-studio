# V1.8.13 验证

## 修改范围

普通混剪预生成缩略图采样由30秒改为60秒，元数据时间点与FFmpeg的选帧间隔一致；小图和悬停大图仍从同一帧分出。前端标题改为“每60秒一张”。3小时整的视频由360组图减少到180组（每组一张小图和一张大图）。仍保留0秒起始帧，因此不足一分钟的视频也有一组。

采样缓存版本更新为v4-paired-60s。若存在完整且与当前视频身份匹配的v3-paired-30s缓存，直接取0、60、120…秒对应图片，重新编号，优先硬链接到新缓存（不可用时只复制缓存图片），不重新解码视频。启动预览队列前完成复用，再移除旧版缓存。旧缓存不完整则走正常60秒预生成。

渲染后后台生成、全部就绪后审核、审核/删除时清理图片的流程保持；音乐Set不生成缩略图的逻辑保持。

## 验证

- 全部369项unittest通过。新增3项验证三小时图片数量、旧缓存隔张复用且不调用FFprobe/FFmpeg、旧缓存不完整时不误判已完成。
- 原有真实视频采样回归改为60秒：70秒红/蓝画面在0/60秒生成两组图片，缩略图与大图颜色均正确；预生成缓存读取不再解码。
- 原有65秒视频审核清理回归通过：两组图片预生成，审核后缓存删除，成片仍保留。
- 最终macOS安装包实际服务与浏览器：新70秒视频实际生成两组0/60秒图片；旧30秒完整缓存复用后仍保持图片inode，旧缓存移除；两种尺寸与实际画面一致；页面显示“每60秒一张”和两个正确时间戳。
- 安装包内版本1.8.13及FFmpeg/FFprobe验证通过。全部实际验证在隔离临时目录中进行，没有改动用户的真实任务或正在运行的后台。

## 性能说明

图片数量及相应缩放、JPEG编码和写盘量约减半，但新视频仍需解码采样，因此不承诺预生成耗时严格减半。已完整生成的旧30秒缓存可直接复用，避免升级引发整段视频重复解码。本轮未增加长视频压力测试。
