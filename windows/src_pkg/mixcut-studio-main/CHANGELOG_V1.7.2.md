# V1.7.2 更新说明

2026-10-11

修复音乐 Set 循环视频模式选择并行 3，仍然只运行一条的问题。

原因：批量启动逐条发送请求，调度器可能提前取走第一条，然后等待固定这一组任务全部结束；后来排队的任务不能补入空位。此外并行数量只在导入时保存，导入后改变页面选择没有传给启动接口。

修复：

- 批量启动一次提交全部选中任务，并在同一调度锁内将它们入队。
- 开始或重试时读取页面当前的 1～4 并行选择，适用于已导入任务。
- 执行池持续补满空位，已完成、暂停或失败的任务释放位置，后续任务继续。
- 原视频混剪与新模式仍共用调度，两种模式不同时占用渲染资源。
- 保留 V1.7.1 的音乐 Set 不抽帧、仅播放审核逻辑。

安装前退出旧版应用及后台，安装后确认顶部为 V1.7.2。选中待执行任务，设置并行数量，再点击开始选中任务即可。
