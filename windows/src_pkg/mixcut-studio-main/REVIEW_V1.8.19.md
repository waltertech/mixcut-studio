# V1.8.19 验证记录

## 问题与修复

用户移动已完成作品目录后，同批后续任务完成会调用 write_manifest，遍历全部成功项并在旧作品路径重写 TXT；目录不存在的异常冒泡至批次调度，阻止后续任务启动。修复只隔离这些附属文档的文件系统错误，不吞掉本地 manifest 的持久化错误。

保存清单时检查目标视频是否存在；已审核作品使用审核记录路径。缺失作品不创建旧目录或孤立 TXT。写入与检查之间发生移动、无权限等 OSError 时记录批次/条目/路径警告，继续其他文档和任务。审核与原素材保护规则不变，不修改独立音乐 Set。
