# V1.7.0 更新说明

发布日期：2026-10-10

## 新增：音乐循环视频

侧栏第 07 页，独立于原来的录屏混剪流程。导入 YouTube Music Cover Maker 4.1 输出的 `YPP交接.txt`、单个 Set 文件夹或包含多个 Set 的上一级文件夹。

- 严格沿用交接文档的完整曲目顺序，每首播放一次，不重新随机或补换歌曲。
- 音乐决定成片时长，动态封面循环播放到音乐结束。
- 默认去除音乐首尾连续静音、加入短交叉过渡，并重新计算实际播放时间轴。
- 沿用动态封面分辨率时，H.264 画面优先直接复用；也可选择 720p / 1080p 转码、30 / 60 fps、音乐音量及 1～4 并行任务。
- 视频完成后提前生成每 30 秒一张的缩略图，全部准备好才允许审核。
- 支持单条和批量开始、暂停、删除任务、一键审核、音乐路径迁移修复，以及按需统计和清理本模式闲置缓存。
- 展开状态保持；收起或离开页面暂停播放。悬停放大的就是当前缩略图。

## 文件规则

- 审核通过：作品与文档保留在原处，清理本模式制作缓存和缩略图。
- 审核不通过：仅将本次生成的作品目录移入废纸篓。
- 删除任务：仅移除记录并清理该任务缓存，已完成作品不动；执行中任务会先取消，未完成临时文件清理。
- 原音乐、动态封面、静态封面、交接文档始终保留。

输出层级：成品路径 / 日期 / 001-成品路径末级名称。每个作品目录包含视频、封面、发布文案和实际曲目时间轴。

## 隔离与回滚

新模式使用独立数据库和缓存目录 `loop-mode`，原有方案、任务、音乐分配和审核文件规则保留。共用调度器，原混剪队列优先，两种模式不同时占用渲染资源。

保留 V1.6.0 源码、安装包和数据快照，详见下载目录中的“MixCutStudio-V1.6.0-回滚备份”。本次交付未替换正在使用的应用，也未修改真实素材。
