## 安装与使用

1. 双击 `MixCutStudio-1.0.0-win64-Setup.exe`。
2. 按向导安装（默认**当前用户**安装，不需要管理员权限，不弹 UAC）。
3. 安装完成后勾选“立即启动”，浏览器会自动打开 `http://127.0.0.1:8877`。
4. 之后从**桌面图标**或**开始菜单 → MixCut Studio** 启动。

安装位置：`%LOCALAPPDATA%\Programs\MixCut Studio`（默认；可用 `/ALLUSERS` 改为装到 Program Files）

开始菜单生成 4 个快捷方式：启动程序、停止后台服务、使用说明、卸载。
安装目录同时附带 `使用说明.md` / `项目说明.md` / `验收记录.md`（上游文档）。

### 退出后台服务

程序是“本地 Web 服务 + 浏览器界面”的结构，**关掉浏览器不会停止后台**，导出任务会继续跑完。
要彻底退出：开始菜单 →「停止后台服务」，或运行 `MixCutStudio.exe --stop`。

### 数据存放

素材目录、导出记录、贴图库、配置都在：`%LOCALAPPDATA%\MixCutStudio`

- `哔哩哔哩` — 默认视频素材目录
- `去重歌曲03` — 默认音乐素材目录
- `exports` — 默认导出目录
- `审核通过` — 默认终审目录
- `.mixcut` — 服务状态、日志（`server.log`）、关键帧缓存

卸载时会询问是否一并删除该目录；选“否”则保留（默认保留），重装后数据可继续用。

## 与上游源码的差异（Windows 移植）

上游只支持 macOS。为在 Windows 上打包运行，对源码做了以下必要修改（均在 `src_pkg/mixcut-studio-main`）：

| 问题 | 上游写法 | Windows 处理 |
| --- | --- | --- |
| 进程互斥锁 | `fcntl.flock`（POSIX 专有） | 新增 `mixcut/lockfile.py`，Windows 用 `msvcrt.locking` |
| 选择文件夹 | 调 `osascript` 弹 macOS 对话框 | 新增 Windows 原生选择器（PowerShell + `FolderBrowserDialog`），中文标题/路径完整往返 |
| 定位文件 | `open -R`（macOS Finder） | 改走资源管理器 `explorer /select` |
| 数据目录 | 写在代码目录（`Program Files` 不可写） | 新增 `mixcut/runtime.py`，写入 `%LOCALAPPDATA%\MixCutStudio` |
| 资源路径 | 相对源码目录 | 兼容 PyInstaller 冻结布局（`sys._MEIPASS`） |
| 原子写盘 | `os.fsync()` 对只读句柄 + `os.link()` | 新增 `mixcut/fsutil.py`；Windows 只读句柄不能 fsync，硬链接在 exFAT/网络盘不支持，改为安全回退 |
| 启动入口 | `启动混剪工具.command` | 新增 `winlaunch.py`：启动器 / `--server` 后台 / `--stop` 停止 |
| 内置 FFmpeg | 依赖系统安装 | 安装包内打包 `ffmpeg.exe` + `ffprobe.exe`，随包即用 |

## 复现构建

一键脚本（可断点续跑）：

```bash
# 需要：Python 3.12+ 与隔离 venv 中的 pyinstaller（图标随包提供，故 Pillow 可选）
python build_tools/build.py                 # 取 FFmpeg → 冻结 → 编译安装包
python build_tools/build.py --skip-freeze   # 只重编安装包（改 .iss 后）
python build_tools/build.py --verify        # 额外跑一遍冻结产物冒烟测试
```

首次运行会自动补齐工具链；若本机已有缓存，可用 `MIXCUT_TOOLS` 指向它避免重复下载约 350 MB。

单独验证脚本：

```bash
python build_tools/verify_frozen.py         # 冻结产物黑盒测试
python build_tools/verify_installed.py      # 已安装程序端到端测试
python build_tools/make_source_zip.py       # 重新打包源代码 zip
```

构建工具链（`_tools/`，已缓存，不入安装包也不入源码包）：

- FFmpeg 9.0.2 essentials（GPL，因渲染使用 `libx264`，必须 GPL 版）
- Inno Setup 6.7.3 + 官方简体中文语言包
- PyInstaller 6.22.3（隔离 venv：`~/.workbuddy/binaries/python/envs/mixcut`）

## 已知事项

- 安装包体积 62 MB，其中约 60 MB 是 FFmpeg/ffprobe 两个静态二进制（每个 105 MB，压缩后约 30 MB）。这是“免安装 FFmpeg、开箱即用”的代价。
- 未做代码签名，首次运行 SmartScreen 可能提示“未知发布者”，需点“更多信息 → 仍要运行”。
- 服务只监听 `127.0.0.1:8877`，并校验 `Host`/`Origin`，仅限本机访问。
- 浏览器异常断开时 `server.log` 可能出现 `ConnectionAbortedError / WinError 10053` 记录，属客户端提前断开连接的正常噪声，不影响运行。
