# MixCut Studio — Windows 移植版源码包

这是 <https://github.com/waltertech/mixcut-studio> 的 **Windows 移植版源代码**。
上游只支持 macOS，本源码包已把平台相关的部分改成跨平台，并附上从源码一键构建
Windows 安装包（`Setup.exe`）的完整工具链脚本。

## 环境要求

- **Windows 10/11 x64**
- **Python 3.10+**（构建需要 3.12+；运行不受限）
- 首次构建需联网（自动下载 FFmpeg 与 Inno Setup，缓存在 `_tools/`，约 350 MB）

## 从源码直接运行（不打包）

```bash
cd src_pkg/mixcut-studio-main
python winlaunch.py                # 启动服务并打开浏览器
python winlaunch.py --server       # 前台运行服务（调试用）
python winlaunch.py --stop         # 停止后台服务
```

需要系统 PATH 里有 `ffmpeg` / `ffprobe`（源码运行时不自带内置二进制）。

## 一键构建安装包

构建依赖放在**隔离虚拟环境**里（不污染系统 Python）：

```bash
python -m venv %USERPROFILE%\.workbuddy\binaries\python\envs\mixcut
%USERPROFILE%\.workbuddy\binaries\python\envs\mixcut\Scripts\pip install pyinstaller pillow
set VP=%USERPROFILE%\.workbuddy\binaries\python\envs\mixcut\Scripts\python.exe
```

然后用该解释器跑构建脚本：

```bash
%VP% build_tools\build.py                  # 完整流程，按根目录 VERSION 命名安装包
%VP% build_tools\build.py --skip-freeze    # 只重编安装包（改了 .iss 之后）
%VP% build_tools\build.py --skip-installer # 只冻结，不编安装包
%VP% build_tools\build.py --verify         # 额外跑一遍冻结产物冒烟测试
```

> 应用图标 `build_tools/mixcut.ico` 已随源码包提供，构建时会直接复用，因此
> **Pillow 只在需要重新生成图标时才是必需的**。

`build.py` 会自动补齐缺失的工具链：

- **FFmpeg 9.0.2 essentials**（GPL 构建）→ `_tools/ffmpeg-bin/`
  渲染使用 `libx264`，**必须 GPL 版**，不能用 LGPL 构建替换。
- **Inno Setup 6.7.3 + 官方简体中文语言包** → `_tools/InnoSetup/`

若机器上已有一份工具链缓存，可用环境变量复用，避免重复下载约 350 MB：

```bash
set MIXCUT_TOOLS=D:\path\to\_tools
%VP% build_tools\build.py
```

## 跑测试

```bash
cd src_pkg/mixcut-studio-main
python -m unittest discover -s tests -v
```

需要 `ffmpeg` / `ffprobe` 在 PATH 中，否则依赖媒体的用例会报错。
本移植版在 Windows + 内置 FFmpeg 下为 **88 项全部通过**。

## Windows 移植改动一览

| 位置 | 上游写法 | Windows 处理 |
| --- | --- | --- |
| `mixcut/lockfile.py` | `fcntl.flock` | Windows 用 `msvcrt.locking`；统一 `acquire`/`release` |
| `mixcut/folders.py` | `osascript` 选目录 | PowerShell `-STA` 调 `FolderBrowserDialog`，结果以 UTF-8 文件回读（中文标题/路径完整往返） |
| `mixcut/folders.py` | `open -R` 定位文件 | `explorer /select,"<path>"` |
| `mixcut/runtime.py` | 资源与数据同在源码目录 | 只读资源走 `resource_root()`（兼容 `sys._MEIPASS`）；可写数据走 `data_root()`（`%LOCALAPPDATA%\MixCutStudio`） |
| `mixcut/fsutil.py` | `os.fsync()` 直接调用 | Windows 只读句柄 fsync 会报 `EBADF`，改为只对可写句柄 fsync 并容忍失败 |
| `mixcut/fsutil.py` | `os.link()` 发布产物 | exFAT/FAT32/网络盘不支持硬链接，失败时回退到复制 + `os.replace` |
| `mixcut/server.py` | 无 `main(argv)`，端口占用无提示 | 支持传入 argv、`--state-dir` 默认落用户目录、端口占用给友好报错 |
| `winlaunch.py` | 无 | 启动器：就绪探测、后台分离进程、`--stop` 优雅停止、无控制台时把 print 重定向到日志 |

上游 `launch.py` 与 `启动混剪工具.command` **保持原样**未改，便于和上游对比。

## 已知事项

- 未做代码签名，安装包首次运行会触发 SmartScreen「未知发布者」提示。
- 服务只监听 `127.0.0.1:8877`，并校验 `Host`/`Origin`，仅限本机访问。
- 安装包体积主要来自 FFmpeg/ffprobe 两个静态二进制（各 105 MB）。
